# HANABI ONLINE — 非公式オンライン協力ゲーム

ブラウザだけで遊べる、花火の基本ルールを参考にした**非公式の独立実装**です。原作のカードイラスト・ロゴは含まれません。2〜5人用で、ルームURLの共有、WebSocketによるリアルタイム同期、ヒント履歴、チャット、再接続、虹色の拡張ルールが付いています。

## 必要なもの

- Node.js **20以上**
- npm
- ゲームに参加する各人のブラウザ（スマホ・PC）
- インターネット公開するときは GitHub と Render 等のホスティング環境

## 自分のPCで起動する

```bash
npm install
npm test
npm start
```

ブラウザで <http://localhost:3000> を開きます。

1. 1人目が名前を入力して「ルームを作成する」
2. 「招待URLをコピー」を押して友達に送信
3. 友達が名前を入力して参加（最大5人）
4. ホストがゲームモードを選択し、全員オンラインなら「ゲームスタート」
5. 手番の人が「自分の手札を選ぶ→プレイ/捨て札」または「相手を選ぶ→色/数字のヒント」
6. 終了後、ホストが「ルームで再戦を準備する」を押すと同じメンバーで再戦できます。

同一PCの複数タブで動作確認したい場合は、**別のブラウザプロファイルかシークレットウィンドウ**を使用してください。通常の同一ブラウザ・同一サイトでは保存済みの参加資格が共有されます。

## Render に公開する

> デプロイには GitHub へのソースコードのアップロードが必要です。ChatGPT側で自動的に公開したわけではありません。

1. ZIPを解凍し、新しい GitHub リポジトリへ `hanabi-online` フォルダ内のファイルをアップロードします（`server.mjs` がリポジトリ直下になるように）。
2. Render で **New → Web Service → Connect a repository** を選択します。
3. **Runtime:** Node / **Build Command:** `npm install` / **Start Command:** `npm start` / **Health Check Path:** `/health` を設定します。
4. 無料枠の場合は Instance Type **Free** を選択してデプロイします。
5. 完成した `https://...onrender.com` を開いて新規ルームを作り、友人に招待URLを共有してください。

`render.yaml` に同じ設定が含まれています。Renderの Blueprint から取り込むこともできます。ポートは Render が指定する `PORT` を自動使用します。

### 無料枠の重要な制限

**ゲームの状態はサーバーのメモリ上にのみ保存されます。** ブラウザのリロード・一時的な切断からは戻れますが、Renderの無料サービスのスリープ、再起動、再デプロイ、クラッシュで進行中のゲームや履歴は消えます。長期保存したい場合はRedis/データベースと認証の設計を追加してください。複数の Node インスタンスに水平拡張する実装でもありません。

Renderの最新条件は公式ページをご確認ください：<https://render.com/docs/free> / <https://render.com/docs/websocket>

## 実装したルール

| 項目 | 基本ルール |
| --- | --- |
| 人数 | 2〜5人 |
| デッキ | 5色×10枚＝50枚。各色の1が3枚、2〜4が各2枚、5が1枚 |
| 手札 | 2〜3人：5枚、4〜5人：4枚 |
| ヒント | 8個開始、相手1人へ色または数字を伝える（該当カードをすべて示す） |
| 捨てる | 1枚捨て、ヒント+1。ヒントが8個なら禁止 |
| 出す | 対応する色の次の数字なら成功。それ以外は失敗し捨て札へ |
| 5の成功 | ヒント+1（最大8） |
| ゲーム終了 | 3失敗（得点0）、全色完成（25点）、山札が尽きた後に全員1ターン |
| スコア | 完成した数字の合計（失敗3回は0点） |

**空ヒント**（該当カード0枚）はこの実装では不可です。原作の版によって扱いが異なるため、一般的な禁止ルールを採用しています。

## 拡張モード

- `classic`：5色50枚、最高25点
- `rainbow5`：第6の虹色を各数字1枚ずつ追加（計55枚）。虹色は「虹」という色でヒントを出せる。最高30点
- `rainbow10`：第6の虹色を基本色と同じ枚数構成で追加（計60枚）。虹色は「虹」という色でヒントを出せる。最高30点
- `rainbowWild`：第6の虹色を各数字1枚ずつ追加（計55枚）。虹色カードは**5つの基本色すべての色ヒントに該当**し、虹という色ヒントは出せない。ただし場に出すときは独立した虹色の花火にのみ出せる。最高30点

拡張モードのルールは、原作の過去の版や多色バリエーションにある構成を取り入れた選択肢です（現行日本語版の同梱構成とは限りません）。

## セキュリティと権利について

- サーバーが正しいカード情報と手番を保有。クライアントはカード位置やヒント条件だけを送ります。
- ゲーム中、自分の手札のスート・数字や山札の中身はサーバーの通知に含まれません。終了後は公開されます。
- 復帰用のトークンはブラウザの `localStorage` に保存します。第三者と復帰トークンやブラウザの保存データを共有しないでください。
- ルームコードは参加用の簡易識別子であり、公開URLを知る人は参加できます。本格的な公開サービスにはアクセス制御・レート制限・モデレーションが追加で必要です。
- チャットで手札情報を直接話す行為はプログラムで禁止しません。友だち同士でフェアプレーしてください。
- オリジナルのテキスト・CSSデザインを用い、原作のカード画像・説明書・ロゴを配布していません。一般公開する場合は名称や商標の扱いも確認してください。
